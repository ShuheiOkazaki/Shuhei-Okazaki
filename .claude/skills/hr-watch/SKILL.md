# hr-watch 週次実行手順

作業ディレクトリはリポジトリ直下。成果物は `hr-watch/` 配下のみを編集する。

## 手順

1. `hr-watch/sources.md`・`hr-watch/tracker.md`・`hr-watch/company-profile.md` を読む。前回ダイジェスト（`hr-watch/digests/` の最新）があれば期間の起点にする。無ければ直近2週間。
2. `sources.md` の優先◎→○の順に WebSearch / WebFetch で巡回し、期間内の新着を拾う。対象は労働法令、社会保険・税、人事施策の義務化、判例・行政指針。
3. 各項目を**一次情報で裏取り**する。裏取りできないものは `要確認` のままにし、根拠にした二次情報の旨を明記。推測で施行日を埋めない。
4. `tracker.md` を更新: 既存IDの施行日・ステータス変更、新規項目の追加（連番）、更新日の記入。「自社への影響」は `company-profile.md` と照合して書く（情報不足なら「要プロファイル入力」）。
5. 施行まで90日以内の項目を抽出し、`hr-watch/digests/YYYY-MM-DD.md`（`_template.md` 準拠）を作成。変更がなくても「新着なし」で作成する。
6. 変更を `hr-watch/` のみコミット（メッセージ例: `hr-watch: YYYY-MM-DD 週次更新`）。pushは指定ブランチへ。PR作成・メール/チャット送信・外部への投稿は、ユーザーの明示指示がない限り行わない。

## 禁止・注意

- 個人情報、契約、財務、認証情報などの機密を台帳・ダイジェストに書かない。
- 法的助言ではない旨を踏まえ、断定表現を避け、一次情報URLを必ず併記する。
- 取得に失敗した情報源は握りつぶさず、ダイジェスト末尾「確認できなかった情報源」に記載する。
