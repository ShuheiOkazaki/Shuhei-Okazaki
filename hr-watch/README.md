# hr-watch: 人事・労務 法改正キャッチアップ

HR関連の法改正・義務化事項を継続的に把握し、自社の対応漏れを防ぐための仕組み。

## 構成

| ファイル | 役割 |
|---|---|
| `sources.md` | 監視する一次情報源の一覧（巡回対象） |
| `tracker.md` | 法改正・義務化の台帳（施行日・対象・対応要否・ステータス） |
| `company-profile.md` | 自社の前提（従業員数・業種など）。対象判定に使う |
| `digests/YYYY-MM-DD.md` | 週次ダイジェスト（新着・直近の施行・期限が近い対応） |
| `../.claude/skills/hr-watch/SKILL.md` | 週次実行の手順（`/hr-watch` で手動実行も可） |

## 運用フロー

1. 週次で `/hr-watch` を実行（定期ルーティン、または手動）
2. 情報源を巡回し、新着を `tracker.md` に追記・更新
3. `digests/` にその週のダイジェストを出力
4. 人事担当が `tracker.md` の「対応要否」「担当」「ステータス」を更新

## ルール

- **一次情報（省令・告示・厚労省/各省庁ページ）で裏取りしたものだけ** `確認済` にする。報道・解説記事のみは `要確認`。
- 施行日が未定のものも「未定」で台帳に載せ、動きがあれば更新する。
- 社内の機密情報（個人情報・契約・財務・認証情報）はこのリポジトリに書かない。
- 台帳は法的助言ではない。最終判断は社労士・弁護士等に確認する。
