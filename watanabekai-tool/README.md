# 渡辺ゼミ 卒論発表会・渡辺会 運営ツール

## 導入（初回のみ）
1. Googleドライブで空のスプレッドシートを新規作成
2. 拡張機能 > Apps Script に `Code.gs` の中身を貼り付けて保存
3. スプレッドシートを再読み込み → メニュー「渡辺会ツール」>「① 初期セットアップ」（初回は権限の承認が必要）

## 毎年の流れ
1. 「設定」シートの黄色いセル（開催日・期・会場・時刻など）を更新 → 式次第・TODO期限が自動更新
2. 「発表者」シートに氏名（連名は「・」）と論文タイトルを入力 → 発表時間が自動計算
3. 「② 出欠フォームを作成」 → 出欠フォーム自動生成、URLが「設定」に記入される
4. 「③ 審査フォームを一括作成」 → 発表者ごとのフォームを生成、URLが「発表者」シートに記入される
5. 「式次第」シートを PDF 出力（ファイル > ダウンロード > PDF）
6. TODOシートのステータスを更新
7. 翌年は「⑦ 新年度の準備」で入力をリセット

## 注意
- 設問は「出欠フォーム設問」「審査フォーム設問」シートで自由に編集できます（既定値は仮のものです）。
- 氏名が入るため、このスプレッドシートはゼミ運営メンバー限定で共有してください。
- フォームの回答は、このスプレッドシート内の「出欠回答○○」「審査_○」シートに溜まります。
